=============================================================================
NEON PORTING REQUIREMENTS
=============================================================================

REGISTER WIDTH DIFFERENCE:
- AVX2: 256-bit (32 bytes per iteration)
- NEON: 128-bit (16 bytes per iteration)
- Impact: 2x more iterations, but same speedup potential (4-8x vs scalar)

INTRINSIC MAPPING (AVX2 → NEON):
- _mm256_loadu_si256 → vld1q_u8 (+ one more for 32 bytes)
- _mm256_sub_epi8 → vsubq_u8 (direct map)
- _mm256_add_epi8 → vaddq_u8 (direct map)
- Most operations have direct NEON equivalents

COMPILATION:
- No Cargo.toml changes needed
- Use #[cfg(target_feature = "neon")] for conditional code
- Build: cargo build --release --target aarch64-unknown-linux-gnu
- Limitation: Compile-time detection only (no runtime CPU check)

=============================================================================
CRITICAL IMPLEMENTATION NOTES
=============================================================================

1. FILTER 1 DECODE IS CORRECTLY SCALAR-ONLY
   Reason: Sequential dependency (out[i] = filtered[i] + out[i - bpp])
   Each output depends on the previous output → cannot parallelize
   NEON implementation should also keep decode as scalar

2. FILTER 2 IS FULLY SIMD-ABLE
   Both encode & decode are parallelizable (no horizontal dependencies)
   Highest priority for NEON porting (2x frequency vs filter 1)

3. PACK/UNPACK IS HIGH-VALUE BUT COMPLEX
   Requires bit-level SIMD intrinsics (not just arithmetic)
   Use: vshlq_u8, vandq_u8, vorrq_u8, vtrn1q_u8
   Consider table lookup (vtbl1q_u8) for certain bit depths

4. OVERFLOW PROTECTION MUST BE MAINTAINED
   All size calculations: use checked_* operations
   Return CafeError on overflow (never panic)
   Especially critical for pack_samples_row (width × bpp × bit_depth)

5. UNSAFE BLOCK PATTERN IS WELL-ESTABLISHED
   Always check bounds BEFORE entering unsafe block
   Loop condition: while i + SIMD_WIDTH <= len
   Use unaligned load/store (no alignment assumptions)
   Pattern is transportable to NEON with minimal changes
