NEON INTRINSIC REFERENCE
================================================================================

Essential NEON Intrinsics for Port:

LOAD/STORE (16 bytes per iteration, vs AVX2's 32):
- vld1q_u8(ptr) - Load 16 bytes
- vst1q_u8(ptr, data) - Store 16 bytes

ARITHMETIC:
- vsubq_u8(a, b) - Subtract u8 vectors
- vaddq_u8(a, b) - Add u8 vectors
- vrhadd_u8(a, b) - Rounded average (useful for Filter 3)

BIT MANIPULATION (for pack/unpack):
- vshlq_u8(a, shift_vector) - Variable shift left per lane
- vshrq_u8(a, shift_vector) - Variable shift right per lane
- vandq_u8(a, b) - Bitwise AND
- vorrq_u8(a, b) - Bitwise OR

TRANSPOSE/PERMUTE (for byte-shuffle):
- vld2q_u8(ptr) - Load & deinterleave 2 channels
- vld4q_u8(ptr) - Load & deinterleave 4 channels
- vst2q_u8(ptr, data) - Store & interleave 2 channels
- vst4q_u8(ptr, data) - Store & interleave 4 channels
- vtrn1q_u8(a, b) - Transpose (interleave)
- vtbl1q_u8(table, indices) - Table lookup (byte permutation)

Loop Pattern:
  while i + 16 <= len {
      let data = vld1q_u8(ptr.add(i));
      let result = vsubq_u8(data, ...);
      vst1q_u8(ptr.add(i), result);
      i += 16;
  }
